# Platformer 3D Adventure

Videojuego 3D tipo Mario Bros desarrollado en Unity 6.3 LTS como proyecto académico universitario.

## Equipo
- Integrante 1 — [Rol]
- Integrante 2 — [Rol]
- Integrante 3 — [Rol]

## Tecnologías
- Unity 6000.3.15f1 (Unity 6.3 LTS)
- Ready Player Me SDK (avatares personalizados)
- Starter Assets - Third Person Character Controller
- Cinemachine, NavMesh, Input System, TextMesh Pro

## Requisitos para clonar
- Unity Hub con Unity 6000.3.15f1 instalado
- Git LFS instalado (`git lfs install`)

## Cómo clonar
```bash
git clone https://github.com/tu-usuario/platformer-3d-adventure.git
cd platformer-3d-adventure
git lfs pull
```
Luego abrir la carpeta desde Unity Hub.
